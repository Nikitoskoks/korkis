# ⚔️ Битва лонгов и шортов

Живые сделки Bybit превращаются в средневековую битву.

- Слева замок лонгов (🟢), справа — шортов (🔴).
- Каждая сделка = воин: покупка шлёт зелёного, продажа — красного. Крупная сделка = сильный боец (больше HP).
- Часть воинов — лучники (стоят у стены и стреляют), остальные — мечники (идут в центр и рубятся).
- Внизу канат показывает перевес за последнюю минуту. Если одна сторона давит (66%+), из её замка выбегает богатырь в короне.

Открой `index.html` в браузере. Сборка не нужна, можно выбрать пару и порог крупной сделки.
