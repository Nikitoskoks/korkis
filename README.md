# 🐋 Детектор китов

Живые крупные сделки с Bybit (фьючерсы USDT) в виде рыб: чем больше сделка, тем больше рыба.
Покупки (зелёные) плывут вверх, продажи (красные) вниз. Мелкие сделки — медузки. Внизу канат: кто давит за последнюю минуту (все сделки).
На ликвидациях появляются акулы: ликвидировали шорта — зелёная акула ест красных, ликвидировали лонга — красная ест зелёных.

Открой `index.html` в браузере. Сборка не нужна. Можно выбрать пару и порог «кита» в $.
